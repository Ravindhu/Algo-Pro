# Stage 6 execution plan: full move of Blue-only features into src/quant (decision D2 = full move)

Plain English. Stage 6 moves five Blue-only features into `src/quant/`, one sub-stage at a time.
Each sub-stage ends with a parity or hand-checked test, a decision note, and a status update.
Stage 5 (remove Blue from the quant path) waits until all of stage 6 is done.

|---|---|---|---|

## Rules for every sub-step

1. Re-read the Blue source and list every outside import first.
2. Port pure logic first. Keep network code in a separate module so it can be tested with stubs.
3. Parity or hand-checked tests in the sandbox where Blue loads; otherwise golden fixtures written on the owner machine.
4. No network call in unit tests.
5. The `Flow stage:` line is set on every new file. The SVG mapping is checked by `test_layout.py`.
6. One decision note per sub-step in `docs/decisions/`.
7. The status note and this plan are updated in the same commit.
