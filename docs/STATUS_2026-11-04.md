# Status note - 2026-11-04

Plain-English summary of what changed today and what is still open.

## 1. Status conflict - resolved
- Code and tests for Phases 0-3 exist in `src/quant/` and `tests/unit/`.
- Test run: 63 passed, 27 skipped, 70 failed.
- All 70 failures have one cause: the `openalgo` package is not installed.
  The sandbox proxy returns 403 for PyPI, so it cannot be installed here.
- Conclusion: the code is in place. It cannot be fully verified until
  `pip install -r requirements.txt` runs on a machine with PyPI access.

- `config/risk_limits.yaml`: order qty 10, order value 10,000, open exposure
  20,000, daily loss 1,000, strategy loss 500, max 1% of ADV per order.
- These are starter values you can change. Any value set to null blocks entries.

- Config: `config/strategies/ocl_keylevel.yaml` (defaults from the strategy's

## 7. Gaps - still open
