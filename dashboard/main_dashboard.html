    Infrastructure
    
      
      

      
      Scheduler
      
      
      
        
        
        
        
      
      
      
      
      
      Broker login runs every trading day at the start time. If the machine is off then, the run happens as soon as it is on and the user is logged in (Windows) or the server boots (Ubuntu). It is never skipped; after 15:30 that day's run is skipped and logged. OS and start time changes need one install run on the machine.
      

      
      Engine
      
      
      
        
        
      
      
      
      Both modes log in to the broker at the start time. Auto: the engine then starts, if that is before 09:15. Manual: the engine waits for the button.
